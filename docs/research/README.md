## Format of a research file

1. **Question:** what the spike had to find out.
2. **Short answer:** the conclusion in a few lines, readable without the rest.
3. **Findings:** the details, explained for someone new to the topic.
4. **Options:** when there is a choice, a comparison table with pros and cons.
5. **Recommendation:** what to do and why. Significant choices become an ADR in [decisions/](../decisions/).
6. **Open points:** what is still unknown and how it will be resolved.
7. **Sources:** links, with the date they were checked.
