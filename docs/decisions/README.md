# Decisions

Architecture decision records (ADRs): one file per significant technical choice, named `ADR-NNN-short-title.md`. An ADR is never rewritten after it is accepted; if the decision changes, a new ADR supersedes it.

## Format of an ADR

1. **Status:** Proposed, Accepted (with date) or Superseded by ADR-NNN.
2. **Context:** the problem and the constraints, explained for someone new to the topic.
3. **Options:** each option considered, with pros and cons.
4. **Decision:** what was chosen.
5. **Consequences:** what becomes easier, what becomes harder, what is now ruled out.
6. **References:** related research files and work items.
